# beyondcy-site

The public site for **beyondcy.co**. In this release it is only a "Stay tuned" page.

- `index.html`: the whole page (inline CSS, no build). To change the copy, edit the block marked `<!-- COPY -->`.
- `logo-beyondcy.png` (the logo, made for dark backgrounds) and the favicons `favicon.ico`, `favicon-32.png`, `favicon-16.png`, `apple-touch-icon.png` (update v2).
- `CNAME`: `beyondcy.co`. GitHub Pages redirects `www.beyondcy.co` here once both DNS records exist.

**Deploy:** Settings → Pages → Source: *Deploy from a branch* → `main` / root. Then set the custom domain to `beyondcy.co` and tick **Enforce HTTPS** once the certificate is issued.
